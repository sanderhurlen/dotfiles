# Ideation techniques

Pick 3–5 per session. Mix analytical and provocative lenses.

## Analytical lenses

- **Journey pain points** — walk through the user's (or process's) journey step by step. At each step: what's slow, confusing, manual, error-prone, or annoying? Each pain point → 1–2 ideas.
- **Jobs to be done** — what is the user actually trying to accomplish ("hire" the product for)? What else could do that job better? What adjacent jobs could we also take on?
- **First principles** — strip the problem to fundamentals. Why does this step exist at all? What would we build if starting from scratch today?
- **Five whys** — ask "why" repeatedly about a problem to reach the root cause; ideate on the root, not the symptom.
- **Stakeholder rotation** — generate ideas from the view of each role: end user, admin, support, sales, partner, management, a brand-new user, a power user.
- **Data & signals** — what data do we already have but don't use? What could we predict, warn about, or automate from it?

## Provocative lenses

- **Inversion** — how could we make this *worse*? Then flip each answer. Or: how would we guarantee failure?
- **10x / 1/10** — what if it had to be 10x better, 10x faster, or cost 1/10? Incremental tweaks don't survive this; new approaches do.
- **Remove a constraint** — what if money, time, tech limits, or regulation didn't apply? Then find the partial version that's possible.
- **Add a constraint** — what if it had to work offline, in one click, with zero training, on a phone, in 30 seconds?
- **Analogy / steal from elsewhere** — how do other industries solve a similar problem? (e.g. how would Uber, a hospital, a game, a bank, IKEA do it?)
- **Zero UI / automation** — what if the user never had to do this step? What could happen automatically, in the background, or be done by AI?
- **What if it were the opposite** — reverse a core assumption (pull instead of push, user does it vs. we do it, free vs. premium, batch vs. real-time).

## Structured recombination

- **SCAMPER** — Substitute, Combine, Adapt, Modify (magnify/minify), Put to another use, Eliminate, Reverse/Rearrange. Run each verb against the subject.
- **Morphological box** — list 3–4 dimensions of the solution (e.g. who / when / channel / pricing) with options for each, then combine options in unusual ways.
- **Combine two ideas** — take two unrelated ideas from the list and force them together.

## Choosing techniques

| Subject | Good fits |
|---|---|
| New feature/functionality | Jobs to be done, journey pain points, analogy, zero UI, data & signals |
| Improve existing product | Journey pain points, SCAMPER, inversion, add a constraint |
| Process/workflow | Five whys, first principles, zero UI/automation, eliminate (SCAMPER) |
| Business opportunity | Jobs to be done, analogy, remove a constraint, morphological box |
| Stuck / ideas feel obvious | Inversion, 10x, opposite, combine two ideas |
